# Multi-Robot Fleet Management System with 2D Simulator

A lightweight, end-to-end **multi-robot Fleet Management System (FMS)** with an integrated 2D simulator, built as a fun project to explore the fundamentals and practical challenges of fleet management in mobile robotics.

The system operates a fleet of robots on a 2D grid using **Neumann neighbourhood movement** and demonstrates how an FMS coordinates multiple robots, handles task completion and blockage,i and replans paths in a dynamic multi-robot environment.

### Modules

- **FMS** — Receives the fleet state and task information, coordinates robot execution, and replans paths when tasks are completed or paths become blocked.
- **Simulator** — Executes the paths generated by the FMS, simulates robot motion, updates robot states, and detects potential collision scenarios.
- **Displayer** — Provides a real-time visualization of the 2D environment, including robot positions, planned paths, goals, and potential collisions.

The entire system is designed around a **multi-threaded execution pipeline** to maintain synchronization between the FMS, simulator, and visualizer while supporting a larger number of robots. The project also serves as a sandbox for experimenting with synchronization, concurrency, path planning, collision handling, and the kinds of edge cases and real-world bugs that arise in multi-robot fleet management systems.

The ultimate goal is to build a small but complete robotic stack that provides hands-on insight into the behaviour and engineering challenges of **large-scale fleet management systems**.
